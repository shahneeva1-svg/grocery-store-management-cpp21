RELATIONSHIPS:
==============

GroceryStore USES (composition):
  - Product* (0..100 objects)
  - Customer* (0..100 objects)
  - Supplier* (0..100 objects)
  - Sale* (0..100 objects)

GroceryStore USES (association):
  - FileManager (for persistent storage)

Sale REFERENCES:
  - customerID (foreign key to Customer)
  - productID (foreign key to Product)

GroceryStore USES:
  - All 5 entity classes for CRUD operations


DESIGN PATTERNS:
================
- Model: Product, Customer, Supplier, Sale (data entities)
- Controller: GroceryStore (business logic)
- Utility: FileManager (data persistence)
- Dynamic Memory: Arrays allocated in constructors, deallocated in destructors
- Encapsulation: All data members private, accessed via getters/setters
- Validation: In setters (prices > 0, quantities >= 0, IDs > 0)
