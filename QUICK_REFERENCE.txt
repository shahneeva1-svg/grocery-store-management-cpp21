# QUICK REFERENCE - Grocery Store Management System

## Core Files Created

### Header Files (.h)
- `Product.h` - Product entity with ID, name, price, quantity, category
- `Customer.h` - Customer entity with ID, name, contact, purchase tracking
- `Supplier.h` - Supplier entity with ID, name, contact, payment terms
- `Sale.h` - Sale transaction with automatic date tracking
- `GroceryStore.h` - Main system class managing all entities
- `FileManager.h` - File I/O operations for persistence

### Implementation Files (.cpp)
- `main.cpp` - Menu-driven interface with 9 operations
- `Product.cpp` - Product implementation with validation
- `Customer.cpp` - Customer implementation with purchase tracking
- `Supplier.cpp` - Supplier implementation
- `Sale.cpp` - Sale/Transaction implementation
- `GroceryStore.cpp` - System controller and business logic
- `FileManager.cpp` - File persistence (CSV-based)

## Key Features Implemented

✅ **Encapsulation** - Private members with public getters/setters
✅ **Constructors** - Default and parameterized for all classes
✅ **Destructors** - Proper cleanup in all classes
✅ **Inheritance** - Ready for extension with base classes
✅ **Polymorphism** - Virtual methods for entity operations
✅ **Dynamic Memory** - Dynamic arrays for entity storage
✅ **File Persistence** - Load/save in CSV format
✅ **Validation** - Input validation with exception handling
✅ **Exception Handling** - try-catch blocks throughout
✅ **Modular Design** - Separate .h/.cpp files for each class

## Main Menu (9 Options)

1. **Product Management** - Add, display, search, update, delete products
2. **Customer Management** - Add, display, search, update, delete customers
3. **Supplier Management** - Add, display, search, update, delete suppliers
4. **Process Sale** - Main transaction: customer + product + quantity
5. **View Reports** - Sales, Inventory, and Customer reports
6. **Save Data** - Manual save to CSV files
7. **Load Data** - Manual load from CSV files
8. **Exit** - Auto-save and close

## Main Transaction Flow (Sale Processing)

```
User Input (Customer ID, Product ID, Quantity)
    ↓
Verify Customer Exists
    ↓
Verify Product Exists
    ↓
Check Inventory (Quantity >= Requested)
    ↓
Calculate Total Amount (Price × Quantity)
    ↓
Deduct from Inventory
    ↓
Add to Customer's Total Spending
    ↓
Record Sale with Date
    ↓
Success Message
```

## Dynamic Memory Usage

```cpp
// In GroceryStore constructor
Product* products = new Product[maxCapacity];      // Array of products
Customer* customers = new Customer[maxCapacity];   // Array of customers
Supplier* suppliers = new Supplier[maxCapacity];   // Array of suppliers
Sale* sales = new Sale[maxCapacity];              // Array of sales

// In GroceryStore destructor
delete[] products;    // Properly deallocate
delete[] customers;
delete[] suppliers;
delete[] sales;
```

## File Structure

```

├── customers.txt     (CSV: ID,Name,Phone,Email,Address,TotalSpent)
├── suppliers.txt     (CSV: ID,Name,Contact,Phone,Address,PaymentTerms)
└── sales.txt         (CSV: ID,CustomerID,ProductID,Qty,Amount,Date)
```

2. `std::out_of_range` - Insufficient inventory, capacity full
3. `std::runtime_error` - Entity not found, file operations
